# Abbildungen der Projektseite

Woher die Bilder in der [README](../../README.md) stammen — damit nachvollziehbar bleibt,
was echte Messung ist und was nicht.

| Datei | Herkunft |
|---|---|
| `banner.png` | Selbst gezeichnet mit Pillow, Motiv aus `src/fbtest/desktop/icons.py`. Keine fremden Marken oder Logos. |
| `plaketten.png` | Selbst gezeichnet statt von shields.io geladen. Ein Projekt, dessen Kernversprechen die Unabhängigkeit von fremden Servern ist, sollte seine Startseite nicht von einem fremden Dienst abhängig machen. |
| `bericht-*.png` | Bericht eines **erzeugten** Testlaufs mit erfundenen Messwerten. So steht in den Bildern kein fremdes Heimnetz. |
| `dashboard-live.png` | Echter Testlauf. WLAN-Modul war abgeschaltet, damit kein WLAN-Name im Bild erscheint. |
| `dashboard-testlaeufe.png`, `dashboard-wiederaufnahme.png` | Dieselbe Datenbank wie die Bericht-Bilder. |

Die Bildschirmaufnahmen entstanden mit einem Browser im Kopflos-Modus bei doppelter
Auflösung und wurden anschliessend auf 1600 px Breite verkleinert. Auf GitHub werden sie
mit rund 880 px dargestellt und bleiben damit auch auf hochauflösenden Bildschirmen scharf.
